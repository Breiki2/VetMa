# Montos cobrados y adeudados manualmente por atención

Los importes pueden variar entre atenciones, por lo que el veterinario ingresa manualmente cuánto cobró y cuánto quedó adeudado, y actualiza esos valores cuando recibe pagos posteriores. Se decidió no mantener precios de catálogo ni un historial de pagos: esto mantiene simple el registro por atención, a cambio de no conservar el detalle cronológico de cada pago.
